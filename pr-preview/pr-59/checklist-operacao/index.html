Área 1 de 5: Visibilidade

Conseguimos acompanhar o andamento do trabalho e ver onde ele fica parado.

  1. No fim do dia, sabemos quais atividades de campo planejadas foram concluídas.

    Escolha uma resposta para esta afirmação.

  2. Quando uma atividade atrasa, ficamos sabendo no mesmo dia.

    Escolha uma resposta para esta afirmação.

  3. Conseguimos dizer em que etapa está cada trabalho em andamento.

    Escolha uma resposta para esta afirmação.

Área 2 de 5: Clareza dos processos

As pessoas entendem as etapas, os responsáveis e as passagens de trabalho.

  1. As etapas dos nossos principais serviços de campo estão escritas em um lugar que a equipe consulta.

    Escolha uma resposta para esta afirmação.

  2. Cada etapa desses serviços tem um responsável definido.

    Escolha uma resposta para esta afirmação.

  3. Quem recebe os dados do campo sabe o que conferir antes de passá-los adiante.

    Escolha uma resposta para esta afirmação.

Área 3 de 5: Consistência

O trabalho importante sai confiável, sem depender da memória de uma pessoa.

  1. Duas pessoas fazendo o mesmo serviço registram as informações da mesma forma.

    Escolha uma resposta para esta afirmação.

  2. Se a pessoa mais experiente ficar uma semana fora, o trabalho segue no mesmo padrão.

    Escolha uma resposta para esta afirmação.

  3. Os registros chegam completos, sem precisar voltar a campo para corrigir.

    Escolha uma resposta para esta afirmação.

Área 4 de 5: Medição

Acompanhamos poucos indicadores úteis e olhamos para eles com regularidade.

  1. Temos até cinco indicadores definidos para a operação.

    Escolha uma resposta para esta afirmação.

  2. Revisamos os números da operação em uma data fixa, como toda semana ou todo mês.

    Escolha uma resposta para esta afirmação.

  3. Sabemos quanto tempo leva, em média, entre a coleta em campo e a entrega do resultado.

    Escolha uma resposta para esta afirmação.

Área 5 de 5: Melhoria contínua

Quando algo dá errado ou demora demais, investigamos a causa e mudamos.

  1. Quando um erro chega ao cliente ou ao relatório, investigamos a causa.

    Escolha uma resposta para esta afirmação.

  2. Depois de investigar um problema, mudamos algo no processo para que ele não se repita.

    Escolha uma resposta para esta afirmação.

  3. Quem está em campo tem um jeito simples de avisar quando algo no processo não funciona.

    Escolha uma resposta para esta afirmação.
